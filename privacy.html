njarvis 개인정보처리방침

시행일: 2026년 11월 19일

1. 어떤 정보를 읽나요

njarvis는 채널 소유자가 Google 로그인으로 허락한 YouTube 채널에 대해 다음 정보만 읽기 전용으로 가져옵니다.

  • 채널 정보와 영상 목록(제목, 게시일, 조회수 같은 공개 통계)
  • YouTube 분석 자료(조회수, 시청 시간 같은 집계 수치)

시청자 개인을 식별하는 정보는 받지 않습니다. 요청하는 권한은 youtube.readonly와 yt-analytics.readonly 두 가지이며, 모두 읽기 전용입니다.

2. 어디에 쓰나요

회사 내부에서 다음 콘텐츠 주제와 운영 방향을 정하는 데만 씁니다. 광고, 판매, 제3자 제공에는 쓰지 않습니다.

3. 어디에 보관하나요

로그인 허락 정보(갱신 토큰)와 읽어 온 수치는 회사 내부 컴퓨터에만 저장합니다. 외부 서버나 다른 회사로 보내지 않습니다.

4. 얼마나 보관하나요

채널 연결을 끊으면 저장한 갱신 토큰을 지웁니다. 읽어 온 집계 수치는 내부 업무 기록으로 남을 수 있습니다.

5. 허락을 거두는 방법

언제든지 Google 계정의 서드 파티 연결 페이지에서 njarvis의 권한을 취소할 수 있습니다. 취소하면 njarvis는 더 이상 채널 정보를 읽지 못합니다.

6. Google API 서비스 사용자 데이터 정책

njarvis가 Google API에서 받은 정보를 쓰고 다른 곳으로 옮기는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. YouTube API 서비스를 쓰므로 YouTube 서비스 약관과 Google 개인정보처리방침도 함께 적용됩니다.

7. 바뀌는 경우

이 방침이 바뀌면 이 페이지에 시행일을 새로 적어 알립니다.
