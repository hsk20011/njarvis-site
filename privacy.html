njarvis 개인정보처리방침

시행일: 2026년 11월 20일

1. 어떤 정보를 읽나요

njarvis는 소유자가 Google 로그인으로 허락한 계정에 대해, 허락한 범위 안의 정보만 가져옵니다. 요청하는 권한은 모두 일곱 가지입니다.

  • youtube.readonly: 채널 정보와 영상 목록(제목, 게시일, 조회수 같은 공개 통계). 읽기 전용
  • yt-analytics.readonly: YouTube 분석 자료(조회수, 시청 시간 같은 집계 수치). 읽기 전용
  • analytics.readonly: Google Analytics(GA4)의 방문 수 같은 집계 수치. 읽기 전용
  • drive.readonly: Google Drive 파일의 이름, 종류, 수정 시각과 문서·시트의 내용을 찾고 읽습니다. 읽기 전용
  • drive.file: njarvis가 직접 만든 문서만 다룹니다. 소유자가 승인한 뒤에만 새 문서를 만듭니다
  • spreadsheets: 소유자가 지정한 시트에 한해, 소유자가 승인한 뒤에만 줄이나 칸을 씁니다
  • calendar.events: 기본 캘린더의 일정을 읽고, 소유자가 승인한 뒤에만 일정을 만들거나 고칩니다. 참석자에게 알림을 보내지 않습니다

시청자 개인을 식별하는 정보는 받지 않습니다. 쓰기는 소유자가 화면에서 내용을 확인하고 승인한 한 건마다 이루어지며, 파일 삭제·공유·권한 변경은 하지 않습니다.

문서와 시트의 본문은 요약이나 답변을 만들 때 잠깐 읽을 뿐 저장하지 않습니다. 기록에 남기는 것은 파일 이름, 종류, 수정 시각, 글자 수 같은 정보뿐입니다.

읽은 내용을 요약하거나 답하기 위해, 필요한 부분만 인공지능(AI) 모델에 보내 처리합니다. 이 내용은 모델을 학습시키는 데 쓰지 않으며, 광고나 제3자 제공에도 쓰지 않습니다.

2. 어디에 쓰나요

회사 내부에서 다음 콘텐츠 주제와 운영 방향을 정하는 데만 씁니다. 광고, 판매, 제3자 제공에는 쓰지 않습니다.

3. 어디에 보관하나요

로그인 허락 정보(갱신 토큰)와 읽어 온 수치는 회사 내부 컴퓨터에만 저장합니다. 외부 서버나 다른 회사로 보내지 않습니다.

4. 얼마나 보관하나요

채널 연결을 끊으면 저장한 갱신 토큰을 지웁니다. 읽어 온 집계 수치는 내부 업무 기록으로 남을 수 있습니다.

5. 허락을 거두는 방법

언제든지 Google 계정의 서드 파티 연결 페이지에서 njarvis의 권한을 취소할 수 있습니다. 취소하면 njarvis는 더 이상 계정 정보를 읽지 못합니다.

6. Google API 서비스 사용자 데이터 정책

njarvis가 Google API에서 받은 정보를 쓰고 다른 곳으로 옮기는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. YouTube API 서비스를 쓰므로 YouTube 서비스 약관과 Google 개인정보처리방침도 함께 적용됩니다.

7. 바뀌는 경우

이 방침이 바뀌면 이 페이지에 시행일을 새로 적어 알립니다.
